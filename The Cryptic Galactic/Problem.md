# Problem Statement
Dalam Aliansi Galaksi Electromeda, para agen antarbintang menggunakan sistem enkripsi khusus bernama **Sandi Caesar** untuk mengirim pesan rahasia. Sistem ini menggeser setiap huruf dalam pesan sebanyak beberapa posisi dalam alfabet, sehingga hanya orang dengan kunci yang tepat dapat mendekripsinya.<br>

![image](https://s3.amazonaws.com/hr-assets/0/1735623117-97934c55ba-Screenshot2024-12-31123051.png)    

Suatu hari, Agen Pluton mencegat sebuah pesan terenkripsi dari agent lainnya. Pada pesan yang Pluton terima, terdapat **$key$** dan **pesan terenkripsi** tersebut. Untuk membaca pesan ini, Pluton membutuhkan keahlian kalian untuk mendekripsi pesan tersebut.

# Input Format
Sebuah integer **$key$**<br>
Sebuah string terenkripsi

# Constraints
$1<= key <= 26$ <br>
$A <= string <= Z$

# Output Format
Hasil dekripsi dari string

# Sample Input
```
7
AOYVBNO AOL LCVSBAPVU AOL NHSHEF BUMVSKLK
```
# Sample Output
```
THROUGH THE EVOLUTION THE GALAXY UNFOLDED
```
