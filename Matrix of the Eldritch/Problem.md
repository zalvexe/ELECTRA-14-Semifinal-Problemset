# Problem Statement
Di Negeri Matrixia, dua penyihir hebat bernama Yuki dan Yuzu bersaing dalam duel matematika untuk menentukan siapa yang paling berkuasa. Mereka masing-masing memiliki sebuah matriks ajaib berbentuk persegi $3$ $x$ $3$. Untuk menentukan pemenang, kamu sebagai wasit harus menghitung **selisih hasil perkalian diagonal utama (primer) dengan hasil perkalian diagonal sekunder** dari masing-masing matriks mereka.<br>

Penyihir yang memiliki matriks dengan hasil selisih diagonal yang lebih besar dinyatakan sebagai pemenang! 

# Input Format
$Matriks[3][3]$ berisi integer milik **Yuki**<br>
$Matriks[3][3]$ berisi integer milik **Yuzu**

# Constraints
$0 <= Matriks[3][3] <= 1000$

# Output Format
Sebuah string **Yuki** apabila Yuki pemenangnya, **Yuzu** sebaliknya, dan **Seri** apabila skor mereka sama.
