# Problem Statement
Di galaksi **Nebula X**, terdapat sebuah konstelasi ajaib berisi tiga planet yang masing-masing mengeluarkan permata bintang dengan nilai yang sangat tinggi. Setiap permata yang ditemukan oleh para penjelajah galaksi akan diberi nilai sesuai dengan ukurannya.<br>
Para penjelajah galaksi sering bersaing untuk mendapatkan permata terbesar dan mengumpulkannya dalam kantong khusus. Namun, setiap tahun, mereka harus mencari **permata terbesar ke-k** dari koleksi permata mereka untuk memenangkan Hadiah Bintang Emas yang sangat langka.<br>

![image](https://s3.amazonaws.com/hr-assets/0/1735620798-ab3b07d24a-Screenshot2024-12-31115212.png)     

Suatu hari, seorang penjelajah, Kai, menemukan sebuah kantong berisi $N$ buah permata dengan nilai-nilai yang tertulis dalam daftar. Bantu Kai untuk menemukan permata dengan nilai terbesar ke-*k*

# Input Fomat
Sebuah integer $N$ berupa banyaknya permata.<br>
Integer $arr[N]$ dipisahkan oleh spasi yang merupakan nilai permata.<br>
Sebuah integer $k$.

# Constraints
$1 <= N <= 1000$<br>
$0 <= arr[N] <= 10000$<br>
$k <= N$

# Output Format
Sebuah integer menyatakan nilai permata terbesar ke-*k*
