# Problem Statement
Di galaksi Andronis, seorang pilot antarbintang bernama Zera menerima panggilan darurat dari stasiun luar angkasa Xenor. Kapalnya, Stellar Wing, sedang berada di koordinat $0$, sementara stasiun Xenor berada di koordinat $x$ dengan $x > 0$ di jalur gravitasi antarbintang.
Kapal Stellar Wing dapat melompat melalui warp dengan panjang lompatan **$1, 2, 3, 4, \; atau \; 5$** tahun cahaya dalam satu kali warp. Tugasmu adalah menentukan jumlah minimum lompatan yang diperlukan Zera agar dapat mencapai Xenor dan menyelamatkan mereka tepat waktu.

# Input Format
Sebuah integer $x$

# Constraints
$0 < x < 9999$

# Output Format
Sebuah integer menyatakan minimum lompatan yang diperlukan

# Sample Input
```
12
```

# Sample Output
```
3
```
